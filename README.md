# Ledger Management System 💰

A secure and scalable full-stack backend system engineered to track financial transactions and manage user accounts efficiently.

## 🚀 Features
- **Secure Authentication:** JWT-based user login and role-based authorization.
- **Automated Verification:** Integrated Nodemailer for automated email verifications upon registration and updates.
- **Robust Ledger Tracking:** Secure tracking and logging of financial transactions.

## 🛠️ Tech Stack
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose ODM
- **Security & Tools:** JWT, Nodemailer, Postman

## 💻 How to Run Locally
1. Clone the repository: `git clone https://github.com`
2. Install dependencies: `npm install`
3. Set up your `.env` file (PORT, MONGO_URI, JWT_SECRET, EMAIL_USER, EMAIL_PASS)
4. Start the server: `npm start`
